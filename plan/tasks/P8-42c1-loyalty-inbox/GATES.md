## G3 — adversarial gate — 2026-11-21 — FAIL (cycle 1)

REVIEW-1 (persisted by script): **BLOCK**. 32 hypotheses, with spoofing, forward gating, the read-only mailbox, secrets,
raw mail, retention, auth and CSRF all refuted.

**BLOCK 1, confirmed by the orchestrator:** `simpleParser` on a fabricated 1001-part message gives
`REJECTED EMAXLEN`. `collect` has no per-message guard around `analyseMessage`, so one unauthenticated message with an
allowlisted From and too many parts (or a header block over 1 MiB) aborts every poll as `source_failed`. It is never
keyed, so it is fetched again each time, and every later UID is starved for the 30-day window. This contradicts Goal 3
(unreadable mail is counted `(unreadable)`, never fatal) and Goal 2.

**Returned to the implementer with:**
- the BLOCK fix;
- REVIEW NIT 2: bound the download itself, and treat an unknown size and an over-cap body as oversize;
- REVIEW NIT 3: bound `source.close()` before the lock is released.

REVIEW NIT 4 (a PATCH racing a poll) is recorded for NITS.md.
